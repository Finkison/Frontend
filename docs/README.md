# 📚 Finkison Frontend Documentation Directory

Central documentation hub for the Finkison Progressive Web App (PWA) client. All client architecture, design systems, offline-first runbooks, and specifications are organized within this directory.

```text
Frontend/docs/

│   └── frontend_architecture.md       # React 18, Zustand state, IndexedDB offline sync

│   └── pwa_deployment.md              # PWA deployment, CDN caching, and Nginx setup

    ├── practice_mode.md               # Practice session & drill execution specs
    ├── requirements.md                # Client functional requirements
    └── tasks.md                       # Component implementation checklist
```
